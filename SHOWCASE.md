```

  ⤢ (scale 0.9 → 1)
┌─────────────┐
│   Modal     │
└─────────────┘
```

### Float
```
Decorative element:
  ↕ (translateY: 0 → -10px → 0)
  ○ (continuous loop)
```

### Pulse
```
Live indicator:
  ● (opacity 1 → 0.5 → 1)
