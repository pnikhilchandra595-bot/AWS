# 🍥 Naruto Anime Theme - Complete Features

## Theme Activation
Click the theme button (moon/sun icon) in the sidebar to cycle through themes:
- Dark → Light → Cyberpunk → **Naruto** 🍥

## Visual Elements

### 1. **Color Scheme**
- Orange and red gradient backgrounds (ninja fire colors)
- Warm brown/orange tones throughout
- Glowing chakra effects on borders

### 2. **Floating Anime Decorations**
When Naruto theme is active, you'll see floating emoji across the screen:
- 🍥 Naruto's ramen swirl (Uzumaki clan symbol)
- ⚡ Lightning/Chidori
- 🔥 Fire Style jutsu
- 🌀 Rasengan spiral
- 🥷 Ninja
- 🗡️ Kunai

### 3. **Ninja Mode Badge**
In the header, a special badge appears showing:
- 🍥 Ramen swirl icon (animated with jutsu-seal rotation)
- "NINJA MODE" text
- ⚡ Lightning bolt (floating animation)

### 4. **Sidebar Ninja Way Card**
Special card in sidebar with:
- 🍥 Animated ramen swirl
- "Ninja Way" title
- "Believe It!" catchphrase
- 🔥 Floating fire emoji
- Chakra flow glow effect

### 5. **Anime Rank Display**
Replaces standard stats chart with Naruto-themed ranks:

**8 Ninja Ranks:**
1. 🎓 Academy Student (Level 1-9)
2. 🥷 Genin (Level 10-19)
3. 📜 Chunin (Level 20-39)
4. ⚔️ Jonin (Level 40-59)
5. 🎭 ANBU (Level 60-79)
6. 🌟 Sannin (Level 80-89)
7. 🔥 Kage (Level 90-99)
8. 👑 Hokage (Level 100+)

Each rank shows:
- Rank icon and name
- Inspirational quote from Naruto
- Progress bar to next rank
- Animated particles
- Stats breakdown

### 6. **Jutsu Unlocked Notifications**
When you achieve milestones in Naruto theme, you unlock jutsu:

- **First concept learned** → 🥷 Shadow Clone Jutsu
- **10 refactors** → 🌀 Rasengan
- **Perfect quiz score** → ⚡ Chidori
- **7-day streak** → 🔥 Fire Style: Fireball Jutsu

Notifications include:
- Confetti celebration
- Jutsu name and description
- Animated icon
- Sound effects (if enabled)

## Animations

### Custom Naruto Animations:
- **jutsu-seal**: Rotating seal animation (180° rotation with scale)
- **chakra-flow**: Pulsing orange/red glow effect
- **ninja-dash**: Fast horizontal dash effect
- **float**: Gentle up-down floating motion

## How to Experience All Features

1. **Switch to Naruto theme** (click theme button 3 times from dark mode)
2. **Check the sidebar** - see the Ninja Way card and rank display
3. **Look at the header** - see the Ninja Mode badge
4. **Notice the background** - floating anime emoji decorations
5. **Complete actions** - unlock jutsu notifications when achieving goals
6. **Level up** - watch your ninja rank progress from Academy Student to Hokage!

## Theme Colors (CSS Variables)
```css
--bg-primary: Orange/brown gradient
--accent-color: #f59e0b (orange)
--text-primary: #fff5e6 (warm white)
--border-color: Orange with glow
```
